# PyNetScan - Local Network Analyzer 🔍

A Python-based network scanning tool that discovers active devices on your local network and checks for open ports.

## Features
- ARP Scan to find all active devices (IP + MAC)
- Port Scanner for security auditing (22, 80, 443, 8080)
- Built with Scapy & Socket

## How to Run
pip install scapy
python pynetscan.py

## Ethical Use Only
Use this tool ONLY on your own network for learning purpose.
